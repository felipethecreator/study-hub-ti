# Study Hub TI

Este repositório foi criado com o objetivo de organizar minha trajetória acadêmica e profissional na área de Tecnologia da Informação.

O Study Hub será utilizado para centralizar materiais das disciplinas, atividades, anotações, projetos e certificados, mantendo uma estrutura organizada e padronizada ao longo da graduação.
