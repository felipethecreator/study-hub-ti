# CashFlow API

API de controle financeiro pessoal desenvolvida por Felipe Rodrigues Queiroz. O projeto organiza categorias e despesas, com autenticação de usuários e persistência em banco de dados relacional.

## Objetivo

Facilitar o registro e a organização das despesas pessoais, incluindo gastos recorrentes, categorias e prioridades. O projeto reúne práticas de desenvolvimento Backend, segurança de APIs e organização do código por funcionalidade.

## Tecnologias

- Java e Spring Boot.
- Spring Security e JWT para autenticação e proteção de rotas.
- Spring Data JPA e PostgreSQL para persistência.
- Flyway para migrações do banco de dados.
- Bean Validation e tratamento de erros.
- Swagger/OpenAPI para documentação da API.
- Maven para gerenciamento das dependências.

## Funcionalidades documentadas e verificadas

- Cadastro e autenticação de usuários.
- Criação, consulta, atualização e exclusão de categorias.
- Gerenciamento de despesas, com valor, prioridade e recorrência.
- Validação de dados e tratamento de erros na API.
- Organização em controllers, services, repositories, entidades e DTOs.

O README original também apresenta um roadmap. Notificações automáticas e exportação de relatórios não são tratadas aqui como recursos concluídos. Para acompanhar a evolução, consulte o código e a documentação no repositório original.

## Relevância para a formação

O projeto permite estudar a construção de APIs REST, autenticação, modelagem de dados, separação de responsabilidades e manutenção de um banco relacional com migrações.
