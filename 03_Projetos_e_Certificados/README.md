# Projetos e Certificados

Esta pasta organiza a documentação dos projetos apresentados no Study Hub e reserva espaço para certificados obtidos ao longo da minha formação.

O objetivo é manter um registro da minha evolução acadêmica e profissional, reunindo experiências práticas e atividades complementares.

## Projetos

Cada projeto possui uma pasta com objetivo, tecnologias, funcionalidades verificadas e links para o repositório original. O código-fonte permanece nesses repositórios, onde seu histórico e suas atualizações podem ser acompanhados.

| Projeto | Área | Documentação | Código-fonte |
| --- | --- | --- | --- |
| CashFlow API | Backend e controle financeiro | [CashFlow_API/README.md](CashFlow_API/README.md) | [cashFlow-api](https://github.com/felipethecreator/cashFlow-api) |
| Swanly | Backend e gerenciamento de usuários | [Swanly/README.md](Swanly/README.md) | [Swanly-backend](https://github.com/felipethecreator/Swanly-backend) |
| Web Portfolio | Frontend e apresentação profissional | [Web_Portfolio/README.md](Web_Portfolio/README.md) | [web-portfolio](https://github.com/felipethecreator/web-portfolio) |

## Certificados

Ainda não há certificados adicionados nesta pasta. Quando forem incluídos, serão identificados com nome do curso ou evento, instituição emissora e data de conclusão, conforme as informações do documento.

## Como manter a documentação

Para adicionar um projeto, crie uma pasta própria com um `README.md`, descreva apenas informações verificáveis e acrescente o link na tabela acima. Ao atualizar um projeto existente, revise suas funcionalidades e os links para o código original.
