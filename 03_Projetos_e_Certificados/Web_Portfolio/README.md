# Web Portfolio

Portfólio web pessoal de Felipe Rodrigues Queiroz, desenvolvido com React, Next.js e Tailwind CSS. O projeto reúne sua apresentação profissional, habilidades, experiências, projetos e formas de contato.

## Objetivo

Apresentar a trajetória e os projetos do desenvolvedor em uma aplicação web, facilitando o acesso às informações profissionais e aos canais de contato.

## Tecnologias

- React e Next.js.
- TypeScript.
- Tailwind CSS.
- Componentes de interface organizados por seção.

## Funcionalidades verificadas no código

- Página composta por seções de apresentação, sobre, habilidades, projetos, experiência e contato.
- Navegação pelo cabeçalho da aplicação.
- Alternância de idioma com atualização do conteúdo e do atributo de idioma da página.
- Layout com regras responsivas e componentes reutilizáveis.

## Relevância para a formação

O projeto permite praticar desenvolvimento Frontend, composição de interfaces com React, estilização responsiva e organização do conteúdo de um portfólio profissional.
